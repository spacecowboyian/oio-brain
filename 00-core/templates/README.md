# Templates

Copy the relevant template, rename the file per the naming conventions in `00-core/repo-standards.md`, and fill in the brackets.

Always add proper frontmatter when creating a new file from a template.

---

## Core Templates (00-core/templates/)

| Template | Use For |
|---|---|
| [sop.md](sop.md) | Any repeatable process that must be done consistently |
| [checklist.md](checklist.md) | Pre-event, post-event, pre-publish, or any task list |
| [vehicle-status.md](vehicle-status.md) | Vehicle overview and current status (one per car) |
| [event-recap.md](event-recap.md) | Post-event write-up — results, mechanical notes, content |
| [video-brief.md](video-brief.md) | Video planning before scripting or shooting |
| [lesson-learned.md](lesson-learned.md) | Single lesson from an event, build, or mistake |
| [meeting-note.md](meeting-note.md) | Call or conversation — who said what, what was decided |
| [sponsor-lead.md](sponsor-lead.md) | Individual sponsorship lead tracking |
| [decision-entry.md](decision-entry.md) | How to format an entry for decisions-log.md |
| [project-plan.md](project-plan.md) | Multi-step project with goals, milestones, and tasks |
