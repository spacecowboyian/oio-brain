# Shot Lists

> One file per video or episode. Use the naming convention below.

---

## Naming Convention

```
YYYY-MM-[Format]-[Short-Title]-Shots.md
```

**Examples:**
- `2026-04-COC-Goblin-Returns-Shots.md`
- `2026-04-FIT-Brake-Bleed-Shots.md`

---

## Shot List Template

```markdown
# Shot List — [Video Title]

**Format:** [FIT / VLG / COC / SHT / SPL]
**Shoot Date:** YYYY-MM-DD
**Location(s):** [Garage / Event / Both]
**Status:** [Planning / Shot / Editing]
```
