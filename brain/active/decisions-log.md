## 2026 Season

### Website Platform & Build

**Date:** 2026-03-31  
**Decision:** Build website with Astro 5 + Tailwind CSS 4  
**Rationale:** 
- Astro optimized for content-heavy sites (45% smaller JS bundle than Next.js)
- Tailwind CSS for rapid responsive design
- Static site generation suits the current scale (1.93K subscribers)
- Integrates YouTube Data API v3 and Instagram Basic Display API
- Can deploy to Vercel or Netlify with minimal friction

**Status:** Built and ready for deployment. Pending: API credentials, GitHub push, domain config.

## Season Planning & Content

### Fit How-To as Top-of-Funnel

**Date:** Early 2026  
**Decision:** Commit to monthly Fit How-To publication (minimum 1 per month)  
**Rationale:** 
- Fit How-To videos are the channel's highest-performing format (top video: 42K views)
- Consistent cadence drives algorithm visibility and subscriber growth
- Low-cost, high-reward content that showcases practical value
- Acts as anchor for the four-week content rotation

**Status:** Active. April video: "Home Alignment / Gyraline" (overdue, target: Apr 2)  
**Metrics:** Monthly publication is non-negotiable; currently tracking against this commitment

### Content Rotation Lock

**Date:** Early 2026  
**Decision:** Four-week content rotation (Fit How-To Week 1, Vlogs Weeks 2 & 4, CoC Week 3)  
**Rationale:** 
- Consistency signals reliability to algorithm and audience
