# Autocross

> Everything OIO needs to know about autocross — the discipline, prep, rules, and how it's different from rallycross.

*Last updated: March 2026*

---

## What Is Autocross

Autocross is a timed motorsport discipline run on a paved surface — typically a parking lot or airfield — defined by cones. Cars run solo against the clock on a course that changes at every event.

**Key characteristics:**
- Surface: Paved
- Course: Defined by cones, changes every event
- Timer: Solo runs against the clock
- Organization: SCCA Solo, regional clubs, local events
- Cones add a 2-second penalty each

---

## Autocross ≠ Rallycross

**This matters. Never flatten them together.**

| | Autocross | Rallycross |
|---|---|---|
| Surface | Paved parking lot | Dirt/gravel/mixed |
| Tire needs | Soft, high-grip | Aggressive, puncture-resistant |
| Setup priorities | Precision, low roll | Durability, suspension travel |
| Driving demands | Accuracy, late apex, smooth inputs | Momentum, commitment, loose feel |
| Prep decisions | Optimize the car | Protect the car |
| Cone penalty | 2 seconds each | N/A or different |

## Car Prep for Autocross

### Pre-Event Checklist
- [ ] Tires — correct spec, fresh if budget allows
- [ ] Tire pressure — set to autocross target (typically lower than street)
- [ ] Alignment — check camber and toe are at target numbers
- [ ] Fluids topped — oil, coolant, brake fluid
- [ ] Brake inspection — fresh pads, good rotors, firm pedal
- [ ] Remove loose items from interior (safety + weight)
- [ ] Safety equipment — helmet (required)
- [ ] Numbers displayed per event requirements

### Post-Event Checklist
- [ ] Tire wear inspection
- [ ] Brake check — feel and inspection after heavy use
- [ ] Reset tire pressure to street spec for drive home
- [ ] Check for unusual noises

## Tire Notes

Autocross tires prioritize:
- Maximum lateral grip on pavement
- Consistent performance across a heat cycle
- Relatively short lifespan — they're being used hard

**Street tire class:** If running Street class, must use street-legal tires
**Performance categories:** Higher classes allow more aggressive compounds
