# Event Notes

> One file per event. Capture notes during or immediately after.

---

## Naming Convention

```
YYYY-MM-DD-[EventName].md
```

**Examples:**
- `2026-04-12-RX-Season-Opener.md`
- `2026-10-18-Lake-Garnett-Revival.md`

---

## Event Note Template

**Location:**
