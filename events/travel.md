# Travel and Packing

> What to bring to every event. Pre-trip checklist and gear list.

*Last updated: March 2026*

---

## Day-of Event Bag (Always)

### Driver Essentials
- [ ] Helmet (required for both disciplines)
- [ ] SCCA membership card / event registration confirmation
- [ ] Logbook (if applicable)
- [ ] Driving gloves (optional but useful)
- [ ] Comfortable shoes for walking the course

### Car Essentials
- [ ] Event tire set (if different from drive tires)
- [ ] Torque wrench (for wheel swap)
- [ ] Tire pressure gauge
- [ ] Floor jack + jack stands
- [ ] Lug wrench / impact
- [ ] Basic tool roll (sockets, wrenches, screwdrivers, zip ties, duct tape)
- [ ] Spare fluids — oil quart, coolant, brake fluid
- [ ] Rags / paper towels
- [ ] Nitrile gloves

### Comfort / Logistics
- [ ] Water (a lot of it — hot parking lots)
- [ ] Snacks / food
- [ ] Sunscreen
- [ ] Folding chair
- [ ] Canopy / shade if staying all day
- [ ] Cash for entry fee if not pre-registered

---

## Filming Gear Checklist

- [ ] 360 camera + mount
- [ ] DJI audio gear (mic, transmitter, receiver)
- [ ] Phone(s) — fully charged
- [ ] Extra batteries (camera + phone)
- [ ] SD cards — clear them before leaving
- [ ] GoPro / action camera if applicable
- [ ] In-car mount secured before leaving home
- [ ] Backup phone for stationary B-roll

---

## Rallycross-Specific Additions

- [ ] Rally tires (if different set)
- [ ] Skid plate confirmed in place
- [ ] Extra air for tires (pressure drops on dirt)
- [ ] Tire plug kit / plug gun
- [ ] More rags — it will be dirty

---

## Autocross-Specific Additions

- [ ] Autocross tires
- [ ] Alignment specs written down (target numbers)
- [ ] Cone-safe interior (remove all loose items)

---

## Multi-Day / Travel Event Additions

- [ ] Hotel / accommodation confirmed
- [ ] Trailer + tow vehicle ready (Al)
- [ ] Spare tire for trailer
- [ ] Generator if needed (paddock power)
- [ ] Fuel for both tow vehicle and race car
- [ ] Enough food/snacks for the full trip
- [ ] Any required rule book / supplemental regulations

---

## Tow Rig — Al (2014 Toyota Tundra)

Pre-trip checks before towing:

- [ ] Hitch and trailer connection secure
- [ ] Safety chains connected
- [ ] Trailer lights working (brake, turn, running)
- [ ] Tire pressure on trailer
- [ ] Car secured on trailer (straps x4 minimum)
- [ ] Mirrors adjusted for trailer width
- [ ] Al's fluids — oil, coolant, tire pressure
