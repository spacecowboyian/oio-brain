## Pattern Summary

### Video Promos
- Always mention link location first
- Tease premise, don't explain everything
- Use 2-4 vivid lines for rhythm
- Strong closer (optional)

### Pit-Talk Casual
- 1-3 sentences max
- Direct, no fluff
- Hashtags carry weight
- Can be one word if earned

### Enthusiast Opinion
- Lead with the take
- Follow-up line optional
- Can be combative in a fun way
- Inside jokes welcome

### Car Mythology
- Car as character
- Arc or challenge hinted
- Emotional investment shown
- Specific details matter

When generating captions:
