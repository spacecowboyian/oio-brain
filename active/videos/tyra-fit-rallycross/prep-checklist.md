# Tyra Fit Video - Prep Checklist

## Before Event Day

**Cameras & Audio**
- [ ] Primary camera charged & tested
- [ ] Backup camera ready
- [ ] Lavalier mic tested with camera
- [ ] Headphones for audio monitoring

**Power & Storage**
- [ ] All batteries charged to 100% + spares
- [ ] Memory cards (2x 64GB+ formatted in camera)
- [ ] Portable SSD + USB reader
- [ ] USB drive (secondary backup)

**Support Gear**
- [ ] Tripod (sturdy for interview)
- [ ] Gimbal/stabilizer (handheld B-roll)
- [ ] ND filter (outdoor exposure)
- [ ] Lens cloths (multiple)
- [ ] Gaff tape

**Weather & Protection**
- [ ] Rain cover for camera
- [ ] Umbrella (shade Tyra)
- [ ] Protective bag/case

**Documentation**
- [ ] Phone with shot list
- [ ] Pen & notepad
- [ ] Backup power pack

---

## Event Day Morning (1 Hour Before)

- [ ] Arrive early
- [ ] Scout interview location (light, noise)
- [ ] Test camera in pit lighting
- [ ] Test audio (lavalier + camera, record 10 sec)
- [ ] Test gimbal balance
- [ ] All batteries 100%
- [ ] Memory cards formatted, SSD ready

---

## During Shoot

### Interview Setup
- [ ] Position car behind/beside Tyra
- [ ] Camera on tripod, 5 ft away
- [ ] Lavalier mic clipped, cable routed safely
- [ ] Test recording (10 sec)
- [ ] Check framing (face well-lit, car visible)
- [ ] Check audio levels

### Backup Procedure (After Each Block)
- [ ] Stop recording, verify audio
- [ ] Remove card from camera
- [ ] Plug into SSD via USB reader
- [ ] Copy files to backup folder
- [ ] Verify file count matches
- [ ] Play back 1 random file (10 sec)
- [ ] Return card to camera, format in-camera
- [ ] Test 10 sec recording

---

## End of Day

- [ ] All footage backed up to SSD
- [ ] Copy SSD to USB drive
- [ ] All gear powered off, cooling
- [ ] All gear packed safely
- [ ] Final pit walk-through (nothing left)

---

## At Home

- [ ] Copy SSD backup to external drive or cloud
- [ ] Verify backup files play (spot check 3-4)
- [ ] Create project folder for raw
- [ ] Note any technical issues
- [ ] Delete nothing until everything is triple-backed-up
