# Shorts and Social Posts

> OIO's approach to short-form content and social media. What to post, when, and how.

*Last updated: March 2026*

---

## Philosophy

Shorts and social posts are:
1. **Top-of-funnel** — they can bring in new viewers who don't find long-form first
2. **Congregation maintenance** — keep the audience warm between uploads
3. **Clip repurposing** — extract value from footage that already exists

OIO is a one-person operation. Social should be efficient, not exhausting.

---

## Shorts Strategy

**Best source material for Shorts:**
- Goblin suffering moments — mechanical failure in real time
- Kids wrenching / surprising moments in How-Tos
- Event moments — close calls, dust clouds, cone penalties
- Project Board reveals — especially when it's overwhelming
- Any moment where Ian is definitively wrong about something

**Format:**
- Hook in first 2 seconds — don't ease in
- 30–60 seconds ideal
- Captions on (auto-gen is fine, correct errors)
- End with a question or tease of the full video

**When to cut a Short:**
- Any time a clip makes you laugh on its own
- Any time a How-To has a satisfying standalone moment
- Any event run that tells a complete story in under 60 seconds

## Social Post Strategy

### YouTube Community Tab
- Use for: behind-the-scenes peeks, Project Board updates, event day announcements, congregation polls
- Cadence: 1–2 per week
- Voice: Same as vlog — casual, honest, Ian talking to friends

### Instagram / TikTok (if applicable)
- Repurpose Shorts content
- Car photos from events and garage
- Behind-the-scenes build progress
- Use relevant hashtags: #autocross #rallycross #hondafit #projectcar #grassrootsmotorsports

## Post Templates

These match the four post patterns in `Social-Post-Voice.md`. Use the pattern that fits the moment.

### Pattern A — Quick Hit
Use for: shop photos, race-day updates, simple reactions.

```
[Observation or opinion].
[One funny or sharp follow-up].
[Tags]
```

**Example:**
```
The Goblin speaketh. Cylinder four is done.
Time to tear it down.
#goblinmr2 #aw11 #rallycross #cars
```

---

### Pattern B — Video Promo
Use for: new upload, race recap, feature video.

```
Video link in the comments.
[Car/person] showed up to [do something dumb, bold, cursed, legendary].
[2–4 vivid lines building intrigue].
[Closing promise or tension].
[Tags]
```

**Example:**
```
Video link in the comments.
Ian's got a Goblin to bring back to life before the hard freeze.
Let's jump in.
#goblinmr2 #aw11 #mr2 #rallycross #cars
```

---

### Pattern C — Car Mythology
Use for: bigger features, rare cars, revival arcs, dramatic builds.

```
[Car] is not [boring thing].
It's [mythic/funny/rough-edged identity statement].
Now it gets thrown into [test/challenge].
[This is only the beginning.]
[Tags]
```

**Example:**
```
Dale is not a museum piece.
It's a prophecy in steel with a fresh 18RG and nothing to prove.
Now it gets thrown at the LGGPR.
This was only the beginning.
#dalesdragon #ra21 #18rg #celica #cars
```

---

### Pattern D — Enthusiast Take
Use for: opinion posts, platform takes, tribe-signaling, Fit vs. Miata content.

```
[Hot take].
[Funny or knowing follow-up].
[Tags]
```

**Example:**
```
There ain't a Miata out there that can best an MR2 on dirt.
Taunting continues.
#goblinmr2 #aw11 #mr2 #rallycross #cars
```

[One honest line about expectations — low or high]

```

### Project Board Update (legacy template)

[Cards added]. [Cards removed]. [One card that's been there too long].

The Goblin card is still there. Obviously.
```

### Congregation Ask / Poll (legacy template)
```
Quick question for the congregation:

[Question relevant to upcoming content or decision]

[Option A / Option B]
```

## CTA Guidance

Use CTAs lightly. OIO should not sound thirsty.

**Best CTAs:**
- Video link in the comments.
- New video is up.
- Let's jump in.
- Go watch the madness.
- Come see how this went sideways.
- See what happened next.
- This was only the beginning.

**Avoid:**
- Don't forget to like and subscribe
- Smash that like button
- Be sure to follow for more
- Check out our latest content
- Let us know what you think in the comments below
