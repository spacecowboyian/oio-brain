# AI-Generated Caption Drafts

This folder contains AI-generated caption drafts for promoting OIO Racing YouTube videos on social media (Facebook, Instagram).

---

## Purpose

These caption drafts are:
- Generated by the AI Copywriter agent using OIO's brand voice guidelines
- Based on published YouTube videos and available transcripts
- Categorized by tone bucket (Story Promo, Enthusiast Opinion, Storytelling/Sermon, etc.)
- Provided as multiple options per video for selection and editing

**These are drafts** — they should be reviewed, edited, and approved by a human before publishing.

---

## Structure

Each file follows this format:

```
Caption-Drafts/
  README.md               — this file
  YYYY-MM-DD_video-slug.md  — one file per video
```

Each caption draft file contains:
- Video metadata (title, URL, date, views, duration)
- Tone bucket classification
- Transcript availability status
- 3–5 caption options with hashtags
- Key context from transcripts when available

---

## How to Use

1. **Review options** — each file has multiple caption variations
2. **Select and edit** — pick the option that fits best, edit for timing/context
3. **Check voice** — compare against `OIO Brain/01 - Brand/Social-Post-Voice.md`
4. **Publish via PostBridge** — use the selected caption when scheduling the post
5. **Archive published version** — published posts get auto-fetched into `OIO Brain/data/social-posts/`

## Quality Guidelines

All caption drafts follow:
- **Voice guidelines:** `OIO Brain/01 - Brand/Social-Post-Voice.md`
- **Post patterns:** `OIO Brain/02 - Content/Shorts-and-Social-Posts.md`
- **Tone buckets:** Story Promo, Enthusiast Opinion, Pit-Talk Casual, Car Mythology, Storytelling/Sermon
- **CTA style:** "Video link in the comments" (never "smash that like button")
- **Hashtag strategy:** Car-specific tags + `#cars` closer
