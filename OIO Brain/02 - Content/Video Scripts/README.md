# Video Scripts

> One file per script. Use the naming convention below.

*Last updated: March 2026*

---

## Naming Convention

```
YYYY-MM-[Format]-[Short-Title].md
```

**Examples:**
- `2026-04-COC-Goblin-Returns.md`
- `2026-04-FIT-Brake-Bleed.md`
- `2026-05-VLG-Project-Board-Update.md`

## Format Codes

| Code | Format |
|---|---|
| FIT | Honda Fit How-To |
| VLG | Vlog |
| COC | Church of Combustion |
| SHT | Short |
| SPL | Special (Sunday School, FIT OFF, etc.) |

---

## Script Template

Copy this to start a new script:

```markdown
# [Title]

**Format:** [FIT / VLG / COC / SHT / SPL]
**Target Length:** [X minutes]
**Status:** [Draft / In Review / Locked / Filmed / Published]
**Publish Date:** [YYYY-MM-DD]

---

## Hook (0:00–0:30)
[What grabs the viewer in the first 30 seconds]

## Body
[Main content]

## Close (last 30–60 seconds)
[Sign-off, CTA, tease of next video]

---
*Sign-off: "Until next time, remember to go out and find your own apex, because it's better late than never."*
```
