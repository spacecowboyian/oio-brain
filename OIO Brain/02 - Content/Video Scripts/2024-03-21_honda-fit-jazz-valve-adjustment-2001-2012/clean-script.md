# Honda Fit / Jazz Valve Adjustment - 2001-2012

You see, the problem with Honda Fits is I can't hardly go to a gas station without somebody trying to make a rap video in front of this thing.

I am Ryan from Ohio Racing, and today we're doing a DIY on my 2007 Honda Fit. When I first got my Fit, it would misfire a little bit on start, and when you'd come up to the first stop sign, it would die every time. This is a common problem with any of these higher mileage cars. The valves need to be adjusted, and they didn't really set an interval for them. Most people don't know that it still has adjustable valves on it. All the older Hondas were adjustable, and the interval was every 60,000 miles. This one never had one done till 209,000 miles.

So it took that long for the problem to come up. What would happen is the valve seats were a little bit soft on these cars, and as the valve seat moved up into the head, it made the valve clearances tighter. So it actually keeps the valves open just a tiny bit to where the motor kind of has low compression. It wasn't that the valves were noisy. On some cars, that's what happens—they get noisy because they get loose from wear. These get tighter.

If you're having those types of problems, maybe this video is for you.
