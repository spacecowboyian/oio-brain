# Results

> One file per season or per event. Use the naming convention below.

---

## Naming Convention

```
YYYY-[Discipline]-[EventName].md
```

**Examples:**
- `2026-RX-Season.md`
- `2026-AX-LakeGarnett.md`
- `2025-Season-Summary.md`

---

## How to Log Results

For each event, record:
- Date and location
- Discipline (RX = Rallycross, AX = Autocross)
- Each driver's runs and best time
- Class and placement
- Cone penalties
- DNFs / incidents
- Notable moments for content
